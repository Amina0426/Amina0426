## 🚀 Featured Projects

### 💰 Budgy — Personal Finance Tracker
A Progressive Web App for tracking income, expenses, and monthly budgets.

- User authentication and cloud data storage with Firebase
- Searchable transactions, tags, and monthly summaries
- JSON backup and restore
- Installable PWA with offline-friendly functionality

**Tech:** HTML, CSS, JavaScript, Firebase, IndexedDB

🔗 [Repository](https://github.com/Amina0426/Budgy)

### 🌱 Habitat — Habit & Goal Tracker
A web app for organizing habits, goals, and progress.

- Create goals, subgoals, and schedules
- Track streaks and progress statistics
- Firebase real-time synchronization
- Installable PWA with theme options

**Tech:** React, Firebase

🔗 [Repository](https://github.com/Amina0426/Habitat)

### 🩺 Breast Cancer Classification
A machine learning project that classifies breast tumors using the Wisconsin Diagnostic Breast Cancer dataset.

- Compared multiple classification models
- Evaluated models with recall, F1-score, and ROC-AUC
- Selected Logistic Regression with a focus on identifying malignant cases
- Deployed an interactive Streamlit application

**Tech:** Python, Pandas, Scikit-learn, Streamlit

🔗 [Repository](https://github.com/Amina0426/breast_cancer_classification)

### 🏡 California Housing Price Prediction
A regression project for predicting housing prices using the California Housing dataset.

- Performed exploratory data analysis and feature engineering
- Compared regression models
- Tuned a Random Forest model using cross-validation and search methods
- Deployed the model with Streamlit

**Tech:** Python, Pandas, Scikit-learn, Streamlit

🔗 [Repository](https://github.com/Amina0426/california_regression)
